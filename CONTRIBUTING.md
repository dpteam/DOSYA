# Как помочь

## Быстрый старт

```powershell
python -m pip install pillow
python tools\setup.py
python tools\build.py host
python tools\smoke.py
```

Если `smoke.py` напечатал `SMOKE TEST PASSED` — всё работает, можно менять код.

## Правила, которые здесь не обсуждаются

**1. Не коммитьте `build/` и `dist/`.** Всё в них генерируется. В
репозитории живут только исходники и генераторы.

**2. Не коммитьте бинарные ассеты.** Спрайт — это ASCII-сетка в
`tools/art_all.py`, а не PNG. Тайл — функция в `tools/gen_tiles.py`.
Причина простая: PNG в диффе не видно, а сетку видно.

**3. Русский текст идёт через `tools/genstrings.py`.** Не пишите кириллицу
прямо в `.c`: DJGPP не умеет `-finput-charset` (падает с `no iconv
implementation`), и вы получите мусор на экране вместо слов.

**4. Градиент задаётся рампом, а не двумя цветами.**
`r_gradient_v(..., PAL_SKY_BASE, PAL_SKY_N, 11, 3)` — правильный вызов.
Пара индексов даст радугу.

**5. Новый уровень должен проходить валидатор.** `tools/genlevels.py`
переставит врагов, которые стоят слишком близко к яме, и напечатает `!!`,
если уровень непроходим. CI на этом падает.

## Что можно сделать

### Легко

* **Новые фразы для экрана смерти.** `tools/genstrings.py`, словари
  `DIE_WATER_*`, `DIE_FALL_*`, `DIE_SPIKE_*`, `DIE_ENEMY_*`. Чем мрачнее, тем
  лучше — но без реального насилия, юмор должен быть про ситуацию.
* **Новый тайл.** Функция в `tools/gen_tiles.py`, добавить в `TILES`, потом
  в `char_to_tile()` / `char_to_bg()` в `src/game.c` и в `tile_flags[]`.
* **Новый враг.** Спрайт в `art_all.py` (два кадра), `E_*` в `enum`,
  поведение в `update_ents()`, размер в `ent_new()`.

### Средне

* **Четвёртый уровень.** См. [docs/levels.md](docs/levels.md).
* **Музыка.** Сейчас только эффекты. Простая зацикленная мелодия через
  PC speaker — реально, но придётся аккуратно с таймингом в `snd_tick()`.
* **Сохранение рекорда.** Пишите в файл рядом с EXE, только не забудьте
  проверить, что он вообще открывается на запись.

### Сложно

* **Sound Blaster.** Нужна детекция карты через BLASTER-переменную и
  работа с DSP. Существенно больше кода, чем весь текущий звук.
* **Второй слой параллакса с тайлами.** Сейчас фон — процедурные холмы.
* **Режим X (320×240).** Больше вертикали, но нужен другой набор регистров
  VGA и пересчёт всей вёрстки экранов.

## Стиль кода

C — C89-совместимый, потому что DJGPP с `-O2` и без плюсов:

* объявления переменных в начале блока;
* `/* */`, не `//`;
* отступ 2 пробела;
* имена: `g_` для глобалов, `s_` нет, локальные просто словами.

Python — PEP 8, но без фанатизма. Главное: комментарии объясняют **почему**,
а не **что**. `// увеличиваем x на 1` не нужен.

## Коммиты

```
game: починить проваливание сквозь платформы

Односторонние платформы проверяли низ персонажа в текущем кадре,
а не в прошлом, поэтому на высокой скорости она проскакивала
насквозь.
```

Первую строку — до 72 символов, в повелительном наклонении. Тело — только
если есть что объяснить.

## Перед пушем

```powershell
python tools\build.py all
python tools\smoke.py
```

CI сделает то же самое, но узнать о поломке через три минуты ожидания
неприятнее, чем через десять секунд.
