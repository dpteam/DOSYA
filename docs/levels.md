# Уровни

Уровни лежат в `tools/genlevels.py` как ASCII-сетки. Каждый — 14 строк.

## Формат

Два слоя.

### Передний план (сталкивается)

| символ | что это |
|---|---|
| ` ` | пусто |
| `#` | земля |
| `=` | трава (верхний слой земли) |
| `%` | трава |
| `B` | кирпич |
| `W` | дерево |
| `F` | забор (декор, сквозь него ходят) |
| `~` | вода (смерть) |
| `^` | грабли (смерть) |
| `H` | сено (декор) |
| `R` | крыша |
| `S` | камень |
| `-` | односторонняя платформа |
| `P` | старт игрока |
| `c` | курица |
| `r` | петух |
| `o` | коза |
| `d` | дед |
| `t` | трактор |
| `m` | молоко |
| `e` | яйцо |
| `n` | навоз (патроны) |
| `v` | самогон |
| `X` | автобус (финиш) |

### Задний план (только декор)

Рисуется затемнённым, не сталкивается.

| символ | что это |
|---|---|
| `1` | бревенчатая стена |
| `2` | соломенная крыша |
| `3` | забор |
| `4` | сено |
| `5` | штукатурка |
| `6` | камень |
| `7` | окно |
| `8` | дверь |
| `9` | торец бревна |

Зачем два слоя: дома в один слой превращают деревню в лабиринт из
невидимых стен. Фон даёт декорации, передний план — то, по чему бегают.

## Валидатор

`genlevels.py` отказывается выгружать уровень, который нельзя пройти. Он
проверяет:

1. **Ровно один `P` и ровно один `X`.** Два автобуса — это два финиша и
   неопределённое поведение.
2. **Ни один враг не внутри стены.**
3. **Ни один враг не ближе 4 тайлов к яме.** Курица на краю ямы превращает
   прыжок в похороны: игрок прыгает, приземляется на курицу, отскакивает
   назад, в яму.

Нарушителей генератор **переставляет**, а не удаляет:

```python
def relocate(g):
    for d in range(1, w):
        for nx in (x + d, x - d):
            if safe(nx) and g.g[y][nx] == " ":
                g.g[y][x] = " "
                g.g[y][nx] = ch
```

Замысел автора (в каком месте уровня стоит враг) сохраняется, а уровень
остаётся проходимым. Если безопасного места нет вообще — уровень соберётся,
но с предупреждением `!!` и CI упадёт.

## Как добавить уровень

```python
def level4():
    W = 150
    g = Grid(W)
    g.ground(0, 20)
    g.ground(26, 50)
    g.fill(21, 13, 25, 13, "~")      # яма
    g.house(8, 5, 4)                  # фон
    g.platform(10, 14, 8)
    g.put(12, 7, "m")
    g.put(30, 11, "c")
    g.put(2, 11, "P")
    g.put(145, 11, "X")
    g.endwall()                       # без этого Дося убежит за край мира
    return g

LEVELS = [

    ("ДЕРЕВНЯ", level2),
    ("ТРАКТОРНОЕ ПОЛЕ", level3),
    ("НОВЫЙ", level4),                # <- добавить сюда
]
```

`g.endwall()` обязателен: без стены в конце уровня игрок проскакивает мимо
автобуса и улетает в пустоту, что выглядит как баг, потому что это баг.

## Посмотреть уровень

```powershell
python tools\showlevel.py 2
```

Печатает сетку с линейкой по колонкам — так удобно считать, насколько широк
разрыв.

## Проверить проходимость

```powershell
python tools\build.py host
python tools\smoke.py
```

Автопилот пробегает все уровни. Он тупой (смотрит на один тайл вперёд), но
именно поэтому полезный: если тупой бот проходит — человек пройдёт точно.

## Правило дизайна

Уровень 3 построен на строгом ритме: 12 тайлов земли, 3 тайла ямы, повтор.
Регулярность — это то, что делает сложный уровень честным: игрок видит
паттерн и решается на прыжок, вместо того чтобы угадывать.
